DAY 13 - PYTHON PATTERN PROGRAMS
===================================

1. NESTED LOOPS
A nested loop means one loop is placed inside another loop.

Basic structure:
for i in range(...):
    for j in range(...):
        statement

2. OUTER LOOP AND INNER LOOP
Outer loop -> controls the number of rows.
Inner loop -> controls the number of columns/items inside each row.

The inner loop completes all its iterations for every one iteration of the
outer loop.

3. print(..., end="")
Normally print() moves to the next line.
Using end="" keeps the next output on the same line.

Example:
print("*", end="")

4. print() AFTER THE INNER LOOP
After the inner loop finishes one row, print() moves the cursor to the next
line.

Example:
for i in range(3):
    for j in range(3):
        print("*", end="")
    print()

Output:
***
***
***

5. BASIC SQUARE PATTERN
For a square:
- Number of rows = number of columns.
- Outer loop controls rows.
- Inner loop controls stars in each row.

6. RECTANGLE PATTERN
For a rectangle:
- Outer loop represents rows.
- Inner loop represents columns.
Example: 3 rows and 5 columns.

7. INCREASING TRIANGLE
The number of items increases with each row.

Example:
*
**
***
****
*****

The inner loop can use range(i).

8. DECREASING TRIANGLE
The number of items decreases with each row.

Example:
*****
****
***
**
*

A reverse range such as range(5, 0, -1) can control the rows.

9. NUMBER PATTERNS
Nested loops can print:
- Increasing numbers
- Repeated numbers
- Reverse numbers
- Continuous numbers
- Palindromic numbers

10. ALPHABET PATTERNS
Characters can be generated using chr().

Example:
chr(65) -> A
chr(66) -> B

So chr(65 + j) can produce A, B, C, ...

11. HOLLOW PATTERNS
For a hollow square or rectangle, print a star when the current position is
on the border.

Typical condition:
i == 0 or i == rows - 1 or j == 0 or j == columns - 1

Otherwise print a space.

12. PYRAMID PATTERN
A centered pyramid needs:
- Spaces before the stars
- Increasing number of stars

For row i:
spaces = n - i
stars = 2 * i - 1

13. INVERTED PYRAMID
An inverted pyramid starts with the largest row and decreases the number of
stars toward the bottom.

14. DIAMOND PATTERN
A diamond can be created using:
- An increasing pyramid
- Followed by a decreasing inverted pyramid

15. PALINDROMIC NUMBER PATTERN
Example:
1
121
12321
1234321

The row first increases and then decreases.

16. NESTED LOOP PAIRS
Two loops can be used to generate all combinations/pairs.

For 1 to 3:
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

17. MULTIPLICATION TABLES
Nested loops can generate tables from 1 to 5.
The outer loop selects the table.
The inner loop generates the multipliers.

18. PATTERN THINKING METHOD
Before writing code, ask:
1. How many rows are there?
2. What changes in each row?
3. How many spaces are needed?
4. How many stars/numbers are needed?
5. Which loop controls the rows?
6. Which loop controls the items?

QUICK REVISION
Outer loop  -> rows
Inner loop  -> columns/items
end=""      -> stay on the same line
print()     -> move to the next line
range(i)    -> useful when row length changes

Golden Rule:
OUTER LOOP = ROWS
INNER LOOP = COLUMNS / ITEMS
