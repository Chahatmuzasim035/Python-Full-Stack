DAY 11 - PYTHON CONDITIONAL STATEMENTS AND LOOPS
=================================================

1. CONTROL FLOW
Control flow determines the order in which statements execute. Conditional
statements make decisions, while loops repeat a block of code.

2. CONDITIONAL STATEMENTS
Main forms:
- if
- if-else
- if-elif-else
- nested if

An if block executes only when its condition is True. An if-else structure
provides two possible paths. An if-elif-else structure checks several
conditions from top to bottom. A nested if places one condition inside another.

3. CONDITIONS
A condition evaluates to True or False.

Common comparison operators:
>   greater than
<   less than
>=  greater than or equal to
<=  less than or equal to
==  equal to
!=  not equal to

The modulus operator (%) is often used with conditions, especially for
checking whether a number is even.

4. LOOPS
A loop repeatedly executes a block of code. Loops reduce repeated statements,
make programs shorter, and are useful for automating repetitive tasks.

Python mainly provides:
- for loop
- while loop

This material focuses mainly on the for loop.

5. FOR LOOP
A for loop visits each value in an iterable.

Common iterables:
- list
- tuple
- string
- set
- dictionary
- range

Syntax:
for variable in iterable:
    statements

6. ITERABLE AND ITERATOR
An iterable is an object that can provide values one at a time.
iter() obtains an iterator from an iterable.
next() retrieves the next value from that iterator.

Conceptual flow:
Iterable -> iter() -> Iterator -> next() -> next value -> repeat

When the iterator has no more values, StopIteration is raised. A normal for
loop handles this internally and stops automatically.

7. range()
range() creates a range object representing a sequence of numbers.

Forms:
range(stop)
range(start, stop)
range(start, stop, step)

Important: the stop value is excluded.

Examples:
range(1, 6)      -> 1, 2, 3, 4, 5
range(1, 11, 2)  -> 1, 3, 5, 7, 9
range(10, 0, -1) -> 10, 9, ..., 1

A negative step allows reverse iteration.

8. if INSIDE A for LOOP
A for loop controls repetition while an if statement controls selection.

Example idea:
for each value
    check a condition
    if True -> execute selected code
    if False -> skip it

9. INDENTATION
Indentation defines which statements belong to a block. A statement can be
inside a for loop but outside its nested if block, so its execution frequency
depends on its indentation level.

10. EVEN NUMBER PROGRAM
An even number has remainder 0 when divided by 2.

Condition:
number % 2 == 0

This condition can be placed inside a for loop to print even numbers from a
range.

QUICK REVISION
--------------
if            -> one condition
if-else       -> two paths
if-elif-else  -> multiple conditions
nested if     -> condition inside another condition
for           -> iterate through an iterable
range()       -> generate a numeric range
iter()        -> create/get an iterator
next()        -> obtain the next iterator value
StopIteration -> indicates that iteration is exhausted
