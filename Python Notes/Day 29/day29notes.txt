Python Exception Handling — Notes

1. What is an Error?

An error is a problem in a program that stops it from running correctly.

2. Types of Errors

Syntax Error

Occurs when Python grammar rules are broken.

Detected before the program runs.

Example: missing closing parenthesis.

Runtime Errors (Exceptions)

Occur while the program is running.

The code is syntactically correct but fails during execution.

Examples: ZeroDivisionError, ValueError, IndexError.

3. What is an Exception?

An exception is an error that occurs during program execution and disrupts the normal flow.

Exceptions can be handled using:

try

except

else

finally

4. Common Exceptions

ZeroDivisionError — division by zero

ValueError — invalid value, such as int("abc")

TypeError — invalid type operation

IndexError — invalid list index

KeyError — missing dictionary key

FileNotFoundError — file does not exist

NameError — undefined variable

AttributeError — undefined attribute/method

5. try, except, else, finally

try → write risky code

except → handle the error

else → runs only when no exception occurs

finally → always runs

6. Important Rules

When an exception occurs inside try, the remaining statements in that try block are skipped.

Python then looks for a matching except block.

If a matching except exists, the exception is handled.

If no matching except exists, the program stops with an error.

A generic except: catches all exceptions, but specific exceptions are generally preferred.

7. Nested try-except

A try-except can be placed inside another try-except when different parts of a program need separate error handling.

8. Real-Life ATM Example

The outer try can handle invalid PIN input, while an inner try can handle withdrawal-related errors. An else block can indicate successful completion.

9. Simple Summary

Error = problem in the program.
Syntax Error = grammar/structure mistake.
Exception = runtime error.
try = risky code.
except = handles error.
else = runs after successful try.
finally = always runs.
